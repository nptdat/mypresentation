Slides for VJAI Meeting #2 - 2026
Reasoning Models in Practice: From Inference-Time to Training-Time Scaling on Verifiable Tasks.

Build slide using [colloquium](https://github.com/natolambert/colloquium)

## Install colloquium

```
uv tool install colloquium
```

The command `colloquium` is enabled

## Build slide

```bash
colloquium build reasoning_models_slides.md
```

## Serve for live reload

```bash
colloquium serve reasoning_models_slides.md
```

## Export slides to PDF

```bash
colloquium export reasoning_models_slides.md
```

- Requires a Chromium-based browser
